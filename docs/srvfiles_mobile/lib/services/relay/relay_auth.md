# services/relay/relay_auth.dart

**File:** `lib/services/relay/relay_auth.dart`

## Purpose

Handles authentication, rate limiting, and session token management for the embedded relay server when in server mode. Delegates PIN validation to `PinService`.

## Exports / Public API

### `RelayAuth`

| Member | Type | Description |
|---|---|---|
| `pinService` | `PinService?` | Set by `EmbeddedRelay.startServerMode`. Used to validate PINs. |
| `currentPin` | `String?` | Plain-text PIN held in memory while server mode is active (used by `handlePin` and `ServerController.autoAuthWithRelay`). |
| `sessions` | `Map<String, bool>` | Active session tokens: `token → true`. Shared with `RelayWsHandler` to validate WS auth messages. |
| `rateLimits` | `Map<String, RateEntry>` | Per-IP failed-attempt counters. |
| `static const maxAttempts` | `int` (5) | Attempts before an IP is blocked. |
| `static const blockDuration` | `Duration` (1 min) | How long a blocked IP must wait. |
| `bool isAuthorized(HttpRequest req)` | — | Returns `true` if the request carries a valid session token in the `X-SrvFiles-Token` header or `?token=` query param. |
| `Future<void> handleAuth(HttpRequest req, String Function() generateUuid)` | — | Handles `POST /api/auth`. Validates the PIN via `PinService.validatePin`, issues a UUID token on success. Enforces rate limiting: after `maxAttempts` failed attempts from the same IP the endpoint returns 429 for `blockDuration`. |
| `void handlePin(HttpRequest req)` | — | Handles `GET /api/pin`. Returns the current plain-text PIN as JSON `{'pin': '...'}`, or 404 if no server mode is active. |
| `void clear()` | — | Resets `sessions`, `rateLimits`, and `currentPin` (called on `startServerMode` and `stopServerMode`). |

## Key behaviors

- **Rate limiting**: tracked in `rateLimits[ip]` as `RateEntry`. On a successful auth the entry is removed. On failure the counter increments; at `maxAttempts` the `blockedUntil` is set to `now + blockDuration`. Subsequent requests check `blockedUntil > now` and return 429 immediately.
- **Token format**: UUIDs generated by `EmbeddedRelay._generateUuid` (passed in as a callback to keep `RelayAuth` pure).
- **WS auth sharing**: `sessions` map is passed by reference to `RelayWsHandler`, allowing it to validate WS `auth` messages without a direct dependency on `RelayAuth`.
- Dependencies: `dart:io`, `dart:convert`, `PinService`, `relay_types.dart`.
